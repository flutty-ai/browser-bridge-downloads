# Flutty browser downloads

Official companion app downloads for Flutty Browser Bridge.

## Flutty for Firefox — preview 0.1.0

Requires an Apple silicon Mac running macOS 14 or later, Firefox 158 or later, and a Flutty account. A Firefox add-on is also required. This preview is not yet available in Mozilla Add-ons; the download alone does not enable browser control.

The companion is signed with Developer ID and notarized by Apple. Download the ZIP from Releases, unzip it, and move Flutty for Firefox.app into Applications. Quit Firefox normally and open Firefox through the companion when using Flutty.

Flutty asks for access separately in each chat. Stop revokes that chat’s access. Keep the companion running while Firefox is using the browser bridge.

This repository contains compiled downloads and checksums only.
